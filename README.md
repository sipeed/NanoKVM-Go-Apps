# NanoKVM Go Apps

This branch is the App catalog used by NanoKVM Go **Settings > Apps > Store**.
Each top-level App directory contains its own `app.json`, `main.py`, and
optional resources or installation scripts.

The shared App SDK, development documentation, and utilities are maintained on
the [`base` branch](https://github.com/sipeed/NanoKVM-Go-Apps/tree/base):

- [English development guide](https://github.com/sipeed/NanoKVM-Go-Apps/blob/base/README.md)
- [中文开发指南](https://github.com/sipeed/NanoKVM-Go-Apps/blob/base/README_zh.md)
- [`appbase.py`](https://github.com/sipeed/NanoKVM-Go-Apps/blob/base/appbase.py)
- [`appbase.pyi`](https://github.com/sipeed/NanoKVM-Go-Apps/blob/base/appbase.pyi)
- [Utilities](https://github.com/sipeed/NanoKVM-Go-Apps/tree/base/_utils)
